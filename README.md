# Sales Tracker – Google Sheets

## 📊 Project Overview

This project is a Google Sheets based Sales Tracker designed to automatically calculate daily, weekly, and monthly sales totals from raw sales entries.

## 🎯 Objective

The main objective is to practice spreadsheet data entry, formulas, automatic calculations, data validation, and sales aggregation.

## 🛠️ Tools Used

- Google Sheets
- SUMIFS
- Basic Excel/Google Sheets formulas
- Data Validation

## 📁 Dataset

The dataset contains:

- Date
- Product
- Category
- Quantity
- Price per Unit
- Total Sales

## 📈 Key Features

- Automatic Total Sales calculation
- Daily Sales calculation
- Weekly Sales calculation
- Monthly Sales calculation
- Product dropdown using Data Validation
- Separate Sales Data and Summary sheets

## 💰 Summary Results

| Metric | Sales |
|---|---:|
| Daily Sales | ₹12,500 |
| Weekly Sales | ₹2,44,600 |
| Monthly Sales | ₹13,54,500 |

## 🧮 Formula Used

Total Sales:

`Quantity × Price per Unit`

Weekly and Monthly totals are calculated using `SUMIFS`.
